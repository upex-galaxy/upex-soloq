## Description

## Description

Panel de control para visualizar y gestionar el estado de las facturas. Incluye filtros, totales pendientes, facturas vencidas destacadas y búsqueda.

## Business Value

Visibilidad completa del estado financiero. El freelancer puede ver rápidamente cuánto le deben, qué facturas están vencidas y priorizar su seguimiento.
